SKTJ COMMAND CENTER — VERSI 1.0

CARA GUNA
1. Buka index.html dengan Chrome/Edge.
2. Pilih modul dan klik Tambah Bahan.
3. Masukkan tajuk, jenis bahan, subjek/kelas dan pautan Google Drive/Slides/Sheets atau website.
4. Klik Simpan Bahan. Gunakan Edit/Padam untuk mengubah rekod.
5. Gunakan Tetapan & Sandaran > Eksport Sandaran JSON secara berkala.
6. Jika bertukar peranti/pelayar, gunakan Import Sandaran JSON.

CARA TERBIT
- Google Sites tidak boleh menjalankan fail HTML ini sebagai website tersendiri secara terus. Untuk hosting, muat naik index.html ke hosting statik seperti Netlify, GitHub Pages atau Cloudflare Pages.
- PENTING: data versi ini tersimpan dalam localStorage peranti/pelayar sahaja. Ia TIDAK diselaraskan antara peranti dan bukan pangkalan data berpusat.
- Jangan masukkan penyata bank, maklumat keluarga, nombor akaun atau data sensitif. Modul PIBG hanya untuk pautan ke fail Google yang dikawal aksesnya.
- Hosting website tidak menyediakan kawalan akses kepada data localStorage. Jangan anggap pautan website sebagai akses peribadi.

PENAMBAHBAIKAN MASA DEPAN
- Sambungan Google Sheets + Apps Script untuk kemas kini merentas peranti.
- Log masuk dan kebenaran akses yang sesuai sebelum data sensitif diproses.

LOGO PERIBADI:
Logo disimpan di assets/logo-cikgu-nazrul.png dan dipaparkan di dashboard serta menu tepi. Untuk tukar logo pada masa depan, gantikan fail PNG itu dengan gambar baharu menggunakan nama fail yang sama.
